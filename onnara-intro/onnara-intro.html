02

범정부 AI 공통기반 API 키와 RAG 컬렉션을 설정합니다. 현행 업무분장과 최근 배부기록을 준비하고 현재 과 명단에서 배부할 사람을 체크하세요.

03

한 건부터 확인하세요

열린 온나라 탭을 새로고침한 뒤 확장 아이콘으로 Side Panel을 엽니다. 시험문서 한 건의 추천 근거와 담당자를 확인하고 접수 준비를 시작하세요.

업무분장 HWPX와 배부이력은 어떻게 준비하나요?

HWPX 원본은 보관하고, 복잡한 표는 담당자별 Markdown 또는 JSON으로 정리하면 업무와 담당자의 관계를 명확히 전달할 수 있습니다. 담당자·부서·담당 범위·제외 범위·적용 기간을 적으세요. 최근 1~2년 배부기록에는 날짜·문서 제목·실제 담당자·정정 여부를 남깁니다. 저장소의 samples/와 RAG 자료 작성 가이드를 참고하세요.

어떤 데이터가 AI로 전달되나요?

문서 제목·발송부서·체크된 현재 과 후보와 RAG 근거를 범정부 AI 공통기반으로 전달합니다. 참고 검색을 켜면 유사 문서의 제목·일자·보고자·부서 등도 추가됩니다. 문서번호·수신일자는 사용자가 켠 경우에만 포함합니다. 문서 본문·첨부파일·실제 온나라 문서 ID와 조직도 계정 식별자는 보내지 않습니다. API 키와 설정은 해당 브라우저 프로필에 저장됩니다.

이 HTML만 열면 실제 문서를 배부할 수 있나요?

이 페이지는 제품 소개와 가상 데이터 체험입니다. HTML 한 파일로 열 수 있고 외부 폰트·CDN·분석 도구를 불러오지 않습니다. 실제 문서배부에는 확장 설치, Edge/Chrome 114 이상, 지원 온나라 사이트(onnara2.saas.gcloud.go.kr) 로그인과 범정부 AI 공통기반 API·RAG 권한이 필요합니다.

점수가 높으면 바로 자동으로 접수하나요?

기본은 사람이 마지막 확인을 하는 방식입니다. 사용자가 분석과 접수 준비를 시작하고 온나라의 일괄접수를 직접 누릅니다. 자동확인 모드도 문서·명단·실제 지정자 일치와 신뢰도 기준을 충족해야 합니다. 조회 실패나 근거 충돌은 사람이 검토합니다. 마지막 확인은 실제 접수를 실행하므로 추천 근거부터 확인하세요.

v1.5.0의 기능 테스트 51개와 Chromium 합성 화면 검증을 통과했습니다. 실제 내부망 인증·검색 권한·접수 처리는 운영 환경에서 별도 확인이 필요합니다. 이 페이지의 문서·이름·점수는 모두 설명용 가상 예시입니다.
