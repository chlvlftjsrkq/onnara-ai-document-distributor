01 / DISTRIBUTION

AI 문서배부

“누구에게 맡길까?”

현행 업무분장 RAG와 유사 제목의 문서 이력을 함께 살펴봅니다. 체크된 현재 과원 안에서 추천하고, 근거와 신뢰도를 확인한 뒤 담당자별 접수를 준비합니다.

02 / SEARCH

전부서 검색

“이전에는 어떻게 했을까?”

부서·기간별 문서를 조회하고 중복 결과를 정리합니다. 추천 카드에서 같은 제목으로 검색을 이어갈 수 있습니다. 조회 범위는 현재 온나라 로그인 권한을 따릅니다.

03 / ASSISTANT

서무비서

“그다음 무엇을 해야 할까?”

규정·지침·서식을 등록하고 근거 있는 절차·기한·필요 서류·다음 할 일을 확인합니다. 인용으로 원문을 펼치고, 서식 초안을 수정·복사하거나 Markdown으로 저장합니다.

04 / GROUNDED, NOT GUESSED.

AI의 제안에는 근거를.
업무의 결정에는
분명한 기준을.

자동화의 속도보다 중요한 것은 판단의 맥락입니다. 확인할 수 있는 원문과 실행 조건을 함께 제공합니다.

지금 유효한 업무를 우선합니다.

현행 업무분장과 체크된 현재 과원 명단을 확인합니다. 과거 보고자 이력은 보조 근거이며, 추천과 충돌하면 사람 검토로 전환합니다.

읽지 못한 것은, 읽었다고 하지 않습니다.

선택적 PDF 본문 분석의 실패·부분 추출 상태를 구분하고 해당 문서는 자동 접수 준비에서 제외합니다. 모든 문서 형식을 자동 변환하는 기능은 아닙니다.

모르는 값은 ‘확인 필요’로 남깁니다.

인용 근거와 기한 원문을 확인하고 등록 서식의 필드만 채웁니다. 공통·기관·개인은 로컬 자료 분류이며 중앙 공유·접근 권한 기능은 아닙니다.

추천과 실제 접수는 구분합니다.

사람 최종 확인이 기본입니다. 사용자가 시작한 온나라 접수 절차 안에서 검증 후 자동확인을 선택할 수 있습니다. AI 추정 신뢰도는 실측 정확도가 아닙니다.

상세 사용 안내 ↗서무비서 · 모의 시연 ↗RAG 자료 준비 ↗
국가기관·지방자치단체 어디서나 바로 쓸 수 있나요?

국가기관·지방자치단체 서무를 지향하지만 모든 기관 화면의 호환성을 보장하지 않습니다. 문서배부는 현재 구현된 온나라 주소(onnara2.saas.gcloud.go.kr)와 로그인·API 권한이 필요합니다. 기관별·GVPN 주소의 수동 검색은 해당 탭에서 접근을 연결합니다. 실제 내부망 인증·기관 규정·접수 절차는 운영 환경에서 검증해야 합니다. 서무비서 채팅은 온나라 탭 없이도 사용할 수 있습니다.

문서 내용이 어디로 전달되나요?

범정부 AI 공통기반·OpenAI·LM Studio·사용자 지정 OpenAI 호환 서버 중 생성형 AI를 선택합니다. 문서 메타데이터·후보·검색 근거는 선택한 서버로 전달됩니다. PDF 분석을 켜면 원문 PDF는 범정부 AI 공통기반 파싱 API로, 추출 본문은 RAG 검색과 선택한 AI 서버로 전달됩니다. LM Studio를 선택해도 RAG·PDF까지 모두 로컬 처리되지는 않습니다. 기관의 정보보안·외부 전송 정책을 먼저 확인하세요.

서무 에이전트가 모든 업무를 자동 처리하나요?

현재는 문서검색·배부 보조와 등록 자료 기반 절차·기한·할 일·서식 초안 제시를 지원합니다. 자율 결재·임의 발송·모든 후속 업무 실행은 하지 않습니다. 기본은 사람 최종 확인이며, 자동확인도 사용자가 시작한 기존 온나라 접수 절차에서 문서·명단·실제 지정자와 신뢰도 기준을 검증한 경우에 한합니다. 원본 HWPX·DOCX 서식을 직접 채우는 기능은 아닙니다.

이 소개 페이지의 시연은 어떤 자료인가요?

설명용 가상 문서·담당자·규정입니다. 실제 행정 문서나 개인정보를 사용하지 않습니다. 단일 HTML로 오프라인에서도 열 수 있으며 외부 폰트·CDN·분석 스크립트를 불러오지 않습니다. 기본·통합·계약 테스트 통과는 실제 모델의 의미상 정확도, 내부망 연동이나 업무시간 단축을 보증하지 않습니다. 구현과 검증 범위는 저장소의 v1.8.0 안내를 참고하세요.
